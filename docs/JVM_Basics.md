## JVM Basics

### JDK, JRE, JVM
- **JDK (Java Development Kit)**: Contains tools to develop Java programs (compiler, debugger, etc.)
- **JRE (Java Runtime Environment)**: Runs Java programs (contains JVM + standard libraries)
- **JVM (Java Virtual Machine)**: Executes bytecode, ensures Java runs on any platform.

### Bytecode
- Compiled Java code is converted into **bytecode** (.class files)
- Bytecode is platform-independent and executed by JVM.

### Write Once, Run Anywhere
- Java code compiled to bytecode can run on any machine with a JVM.
- Example: `HelloWorld.class` works on Windows, Linux, or Mac without changes.
